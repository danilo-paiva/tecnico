O projeto deve funcionar no dia da apresentação. O não funcionamento implica em nota zero. Todos os exercícios devem fazer parte de um site com navegação completa, ou seja, deve possuir uma página inicial, com um menu para selecionar entre os exercícios, deve ser utilizado css nos formulários e respostas. A utilização de bootstrap é obrigatória. Utilize as cores do bootstrap para representar os resultados da melhor forma possível. Obrigatório rodar a aplicação em um servidor web local.
Crie classes, formulários e endpoints para resolver os problemas abaixo:
Sistema deve possuir uma classe Pessoa com os seguintes atributos privados: (nome, peso, altura). Criar métodos getters e setters para os atributos. Criar um método que calcule o IMC (Índice de Massa Corporal).  Criar um método que classifique o IMC em: abaixo do peso, peso normal, sobrepeso e obesidade.
Criar uma aplicação que possuía a classe Produto com os atributos nome, preço e qtdEstoque. Devem ser criadas formas de adicionar itens ao estoque, remover itens do estoque e calcular o valor total do estoque. O formulário da aplicação deve permitir o envio de dados de 5 produtos, contendo os seguintes dados: nome, preço, quantidade de entrada e quantidade de saída. Dica, criar um vetor de objetos Produtos para facilitar o calculo do valor e total de itens no do estoque. Para cada produto apresentar, o nome do produto, a quantidade e o valor total($) em estoque daquele produto
O sistema deve possuir uma classe Nota responsável por representar as notas de um estudante. A classe deve possuir os atributos nome do aluno, nota1 e nota2. Devem ser criados métodos para calcular a média das notas e determinar a situação do aluno. A situação pode ser: aprovado, recuperação ou reprovado. Considere reprovado notas menores do que três.
O sistema deve possuir uma classe Funcionario com os atributos nome, valorHora e valorHoraExtra, qtdHoras, qtdHorasExtras. Devem ser criados métodos para calcular o salário final do funcionário. O sistema deve mostrar o salário final calculado.
O sistema deve possuir uma classe Triangulo que permita armazenar os três lados de um triângulo. Devem ser criados métodos para verificar e determinar o tipo de triângulo formado pelos lados informados, considerando: triângulo equilátero (três lados iguais), triângulo isósceles (dois lados iguais) e triângulo escaleno (todos os lados diferentes). A classe também deve possuir métodos para calcular o perímetro e a área do triângulo. As invariantes do objeto devem garantir que os lados sejam maiores que zero e que respeitem a regra de existência do triângulo. Para calcular a área considerar Heron.
